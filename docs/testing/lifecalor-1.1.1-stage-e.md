# LifeCalor 1.1.1 阶段 E：统一选项

## 实现范围

- 将首个空“主窗口”菜单替换为“选项”，提供六个分类入口。
- 六个入口打开同一个非模态窗口；重复打开只切换页面并聚焦。
- 新增常规与更新、外观与画布、绘图默认值、计算与加速、寿命拟合默认值、缓存与存储页面。
- 保留旧方法名作为页面定位入口，不再从“编辑”菜单维护重复设置入口。
- 将计算设置表单抽成可嵌入页面，保留旧 `ComputeSettingsDialog` 兼容外壳。
- 新增按算法精度覆盖；未设置时跟随全局，寿命拟合单精度在未验收前禁用。
- 历史缓存页只保留概览、打开目录、清理命令和统一选项深链接。

## 设置语义

- 打开窗口、切页、选色和恢复默认只修改窗口草稿。
- “应用”与“确定”才写入原有 QSettings 键和主窗口参数字典。
- “取消”不写入主题、工具、绘图、寿命、计算或缓存设置。
- 应用只写用户实际改动字段；其他入口在窗口打开后更新的无关字段不会被旧快照覆盖。
- 同一字段发生外部修改时停止应用并提示重新打开选项。
- 缓存目录切换复用现有运行时配置与提示逻辑；旧目录不搬移、不删除。
- 运行中和已排队任务继续使用提交时的计算参数，新设置只影响之后提交的任务。
