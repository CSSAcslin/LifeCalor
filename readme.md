# LifeCalor / Carrier Lifetime Calculator

LifeCalor 是一套基于 PyQt5 的本地科学成像数据分析工具。它面向带时间轴的二维成像序列，覆盖数据导入、画布与 ROI 交互、载流子寿命分析、EM-iSCAT 时频分析、多数据数组运算、结果绘图、历史缓存和多格式导出。

当前版本：`1.0.11`

## 快速开始

开发环境中，在项目根目录运行：

```powershell
python core/MainWindow.py
```

推荐按以下顺序完成一次分析：

1. 在左侧选择分析模式，并填写时间步长、空间步长、FPS 等基础参数。
2. 在当前模式的“导入设置”中选择文件或文件夹。
3. 等待后台导入完成，在画布选择窗口中新增画布或覆盖现有画布。
4. 使用画布工具查看帧、设置伪彩、绘制 ROI，并点击“确认”生成可处理选区。
5. 在左侧选择寿命、STFT/CWT、统计或其他计算方法并执行。
6. 在“数据结果”、历史数据树或画布工具栏中检查、绘图和导出结果。

状态栏显示当前前台任务。需要查看所有任务时，打开“控制台 -> 显示/隐藏任务面板”。

## 界面概览

- **左侧参数区**：分析模式、导入参数、基础时空参数和当前算法设置。
- **中央图像区**：一个或多个画布、帧时间轴、伪彩显示及 ROI 交互。
- **数据结果区**：曲线、直方图和算法结果图。
- **底部状态栏**：运行状态、鼠标位置/像素值及当前任务进度。
- **任务面板**：每个后台任务的独立状态、进度、耗时、取消按钮和错误详情。
- **控制台**：运行信息和诊断日志的界面视图。

主菜单提供以下入口：

- **编辑**：坏点处理、计算设置、绘图设置、缓存设置。
- **数据操作**：多数据计算器、数据切片器。
- **历史数据**：历史与缓存管理、导入历史、处理历史及完整数据树。
- **使用指南**：内置的通用、超快成像和 EM-iSCAT 帮助。
- **检查更新**：查询 GitHub Release，并由用户决定是否下载更新。

## 数据导入

### 通用文件导入

在左侧选择“通用文件导入”，可使用自动识别或指定格式：

| 格式 | 当前支持内容 | 说明 |
| --- | --- | --- |
| NumPy NPY | 数值型一维、二维、三维及高维数组 | NPY 通常不包含物理单位，使用左侧时空参数补充 metadata |
| TIFF / OME-TIFF | 灰度图、图像序列、Palette TIFF、RGB/RGBA、OME 轴信息 | OME 物理尺度和时间信息会尽量保留；彩色数据分析值按亮度生成 |
| AVI / MP4 | 常规视频序列 | 使用文件 FPS 或界面时间基准建立时间轴 |
| Andor SIF | Andor 相机数据 | 保留可读取的采集参数和尺度信息 |
| HDF5 | 文件中的数值数据集 | 导入前会弹出数据集选择器；非数值 dtype 不支持 |

TIFF 可选择“保留 TIFF 颜色显示”或“转换为灰度显示”。保留颜色只影响显示来源；科学计算仍使用对应标量数据。

### 专用导入流程

- **超快成像动态分析**：支持 TIFF 序列文件夹和 SIF 文件夹，可设置 `n`、`p` 或不区分分组；SIF 提供 linear、percentile、sigmoid、log、clahe 等归一化方式。
- **EM-iSCAT**：支持 AVI 文件和 TIFF 序列文件夹，并可设置背景帧数后执行预处理。

### 数据轴与分类

LifeCalor 使用 `T/H/W/C` 描述时间、高度、宽度和通道轴。数据树会将内容分类为：

- 标量
- 向量
- 线性数据
- 图片，即二维矩阵
- 视频，即三维矩阵且一轴明确为 `T`
- 三维矩阵，即没有视频语义的三维数据
- 高维数据

高维或轴语义不明确的数据可以被导入、缓存和用于计算器，但不会被静默当成普通视频显示。需要显示时，应先通过计算器转换为 `HW`、`THW` 或受支持的彩色图像形状。

## 画布与 ROI

### 画布操作

画布区支持新增、删除和切换画布。导入或处理得到新图像时，可选择新增画布或覆盖指定画布。

常用交互包括：

- 拖动时间轴或播放按钮切换视频帧。
- 鼠标悬停查看坐标、当前显示值和原始实际值；数值会随播放帧更新。
- 使用“样式”设置伪彩方案、显示范围和边界方式。
- 在画布空白处右键，可裁剪当前时间范围、强劲裁剪数据、重设参数、开启同步播放/滑动、导出画布或查看当前画布数据详情。
- 多画布同步开启后，播放和时间轴拖动会联动。

“查看当前画布数据详情”会显示来源、数据分类、Shape、dtype、Parameters、Other Results 和当前画布状态，不会为了展示详情扫描完整大数组。

### 绘图与选区工具

工具栏包含画笔、直线、矩形、椭圆、橡皮擦、填充、光标 Anchor、向量线选区和矩形选区。对工具按钮右键可以设置画笔宽度、边框/填充颜色、矢量颜色或选区宽度。

完成选区后点击“确认”，将当前 ROI 接入后续处理。点击“重置”可恢复画布初始交互状态。

### Anchor 快速提取

右键 Anchor 打开“设置快速提取功能”，可设置区域形状、尺寸和统计方法。当前支持平均值、最大值、最小值、中位值、0.75 分位数、标准差、求和、方差和值分布统计。

二维图像没有时间序列，Anchor 快速提取仅使用“值分布统计”。分布统计按当前显示帧 ROI 内的实际科学数值计算，并在数据结果区使用 Histogram 模式显示。

## 超快成像分析

当前主要工作流包括：

- **选区寿命热图**：对确认后的 ROI 计算像素级寿命，可设置起始帧、卷积方式和多进程核心数。
- **指数衰减寿命曲线**：对方形或圆形区域计算平均衰减曲线、拟合寿命和拟合质量。
- **载流子扩散系数计算**：依次计算 ROI 全时信号、输入需要分析的帧、计算选定时刻信号，再显示方差演化和扩散系数。
- **选区分布统计**：对当前帧 ROI 的实际值计算频数分布，可配置 bin 数或使用自动范围。

寿命热图支持不使用卷积、smooth、gaussian、sharpen、edge、laplacian 和 average 等前后处理选项。

目前请优先使用**单指数衰减**。双指数入口仅用于区域曲线的实验性验证，像素级双指数热图尚未形成可靠实现，不建议用于正式结果。

## EM-iSCAT 分析

推荐流程：导入 AVI 或 TIFF 序列 -> 设置背景帧 -> 执行预处理 -> 选择时频方法 -> 设置参数 -> 执行分析 -> 在画布或数据结果区检查并导出。

当前功能包括：

- STFT 短时傅里叶变换，支持 Hann、Hamming、Gaussian、矩形、Blackman 和 Blackman-Harris 窗。
- CWT 连续小波变换及多种小波参数。
- STFT/CWT 质量分析和时频结果快捷导出。
- 全细胞电生理分析中的 ROI 信号均值和二维傅里叶变换。
- 单通道电生理分析中的累积时间振幅图、ROI 二维高斯拟合和单通道提取。

STFT 当前使用 Python 实现。CWT 界面保留 Python/Julia 选项，正式使用建议选择已经验证的 Python 路径。

## 多数据计算器

从“数据操作 -> 数据计算器”打开。计算器启动时保持空白，不会自动载入全部历史数组。

1. 点击“添加数据”，从通用历史树中选择 `Data`、`ProcessedData` 或 `out_processed` 数组，系统依次分配 `A/B/C...`。
2. 也可以点击“从文件导入”，复用主界面的通用导入任务，导入完成后加入下一个数据槽。
3. 在“预切片”列为单个数据设置索引，或直接在表达式中切片。
4. 输入表达式；“验证路径”会逐步显示输入 Shape、输出 Shape、dtype、预计内存和失败步骤。
5. 在“数据预览”中输入从 0 开始的帧号并点击“读取帧”。预览按需读取，不建立整段帧缓存。
6. 在“结果参数”中选择 metadata 继承来源，并确认 FPS、时空步长、单位和结果轴。
7. 点击“执行运算”。任务在后台运行，结果统一生成 `ProcessedData`，可继续显示、处理、缓存和导出。

常用表达式示例：

```python
A - B[42, :, :]
(A - B) / B
mean(A, axis=0)
where(A > 0, A, 0)
transpose(A, axes=(1, 2, 0))
clip(abs(A), 0, 1)
```

计算器支持逐元素四则运算、幂、取模、比较、NumPy 广播、整数/冒号切片，以及 `mean`、`max`、`min`、`sum`、`std`、`abs`、`sqrt`、`log`、`clip`、`where` 和 `transpose`。表达式使用安全 AST 白名单执行，不支持任意 Python 代码、属性访问或未知函数。

## 数据切片器

从“数据操作 -> 数据切片器”打开。切片器适合对空间范围和时间范围进行可视化裁剪，处理结果会生成新的 `ProcessedData`，保留来源、裁剪范围和基础 metadata，并可再次进入画布、历史树或计算器。

## 数据结果与历史树

“数据结果”区域用于显示曲线、拟合结果和 Histogram。曲线图例支持隐藏、重命名和删除等交互。

历史数据菜单提供：

- **历史导入查看**：查看本次导入的原始数据。
- **历史处理查看**：查看本次生成的处理结果。
- **所有历史详情查看**：按树结构查看数据、参数和 `out_processed`；一维数据可加入绘图区，图像数据可建立为新的处理结果并添加到画布，也可直接导出纯数据。
- **本次历史清除**：清空当前会话的内存历史，不删除已经持久化的可恢复缓存。

## 历史与缓存管理

从“历史数据 -> 历史与缓存管理”进入统一管理窗口。

### 当前历史

可以按类型、名称、Shape、dtype、缓存状态、体积和时间排序，并执行：

- 设为当前数据
- 强制缓存落盘
- 删除选中历史

强制落盘会为数据生成 `.npy` 数组文件和 manifest 索引，使其可以在下次启动后恢复。删除历史时，只有明确选择同步删除且缓存不再被其他历史引用，才会移除对应文件。

### 可恢复历史

可恢复历史来自缓存 manifest，可执行恢复、删除索引和刷新。恢复后的 `Data` 或 `ProcessedData` 会直接加入当前历史并可继续显示和处理。若缓存文件被外部删除，刷新后会显示缺失状态；清除无效或全部缓存时，相应索引也会同步更新。

### 缓存设置

- **缓存目录**：可选择位置，也可点击“打开目录”直接查看文件。
- **写入阈值**：默认 `512 MB`。按数组真实 `nbytes` 判断，正确区分 uint、float 和 complex dtype。
- **内存预算**：默认 `4096 MB`。导入和计算会估算源数据、结果及临时副本的驻留内存，超预算时先提示而不是直接分配。
- **启动清理临时缓存**：只清理未完成写入留下的临时文件，不删除 manifest 中的持久缓存。
- **清除孤立缓存**：删除没有有效索引引用的缓存文件。
- **清除全部缓存**：删除缓存文件并同步清空可恢复历史索引；执行前请确认数据已经另行保存。

切换缓存目录后，新缓存写入新目录，旧目录中的缓存不会自动迁移或删除。需要恢复旧缓存时，将目录切回原位置并刷新可恢复历史。

大数组缓存使用 NumPy `.npy` 格式。`data_origin`、`data_processed` 和大型 `out_processed` 都可以由磁盘引用代替内存深拷贝；metadata 始终随历史项保存。读取和写入采用分块 I/O、连续进度和临时文件原子替换，取消或失败不会留下可恢复的半成品。

## 后台任务与取消

导入、缓存读写、寿命计算、EM 预处理、STFT/CWT、ROI 处理、计算器和导出使用统一任务登记。

- 状态栏显示最近的前台任务。
- “控制台 -> 显示/隐藏任务面板”显示所有任务的独立进度和耗时。
- 可在任务面板取消指定任务。
- 按 `Esc` 请求取消当前前台任务。

取消是协作式的：程序会在下一个安全检查点停止当前分块、帧循环或计算阶段，因此超大任务可能不会在按键瞬间结束。取消操作不会在 GUI 线程等待工作线程退出，界面应保持响应。

## 导出

### 画布与图像结果

画布工具栏或画布右键可导出：

- TIFF
- AVI
- GIF
- PNG
- Matplotlib 图片

伪彩显示与导出使用同一套逐帧渲染参数，因此可以导出当前伪彩效果，同时不会为整段视频额外生成完整 RGBA 副本。

### 纯数据

从完整历史树进入“直接导出”，支持：

- CSV：二维数据，或从三维数据中选择一帧
- HDF5
- NPY
- TIFF

导出前请确认目标目录、文件名、帧范围、FPS/持续时间和是否需要当前画布样式。大批量导出可在任务面板查看进度和失败详情。

## 错误、日志与故障排查

LifeCalor 将 info、warning、error 和 critical 全部写入日志：

- warning 只进入日志、控制台或状态栏，不弹窗打断操作。
- error/critical 进入统一错误队列，同一错误只显示一个结构化弹窗，不会把 traceback 按行拆成多个窗口。
- 未捕获异常会记录阶段、异常类型、数据名称、Shape、dtype 和 traceback 等可用上下文。

日志位置：

- 开发环境：`core/carrier_lifetime.log`
- 打包程序：`%LOCALAPPDATA%/LifeCalor/carrier_lifetime.log`

日志采用轮转保存，单文件最大 5 MB，保留 3 个备份。反馈问题时，建议同时提供操作步骤、数据 Shape/dtype、任务面板状态和对应日志片段。

常见检查顺序：

1. 确认数据分类和轴是否符合目标算法要求。
2. 确认当前数据和 ROI 已选择，且 ROI Shape 与画布匹配。
3. 检查任务面板中的失败任务和错误详情。
4. 检查内存预算是否低于本次计算的预计峰值。
5. 查看 `carrier_lifetime.log` 中同一时间点的完整异常。

## 高分屏与界面缩放

程序会在创建 Qt 应用前启用高 DPI 缩放和高分辨率图标，并使用点大小统一全局对话框、按钮和 Tooltip 字体。修改 Windows 分辨率或缩放比例后，建议重新启动程序，让 Qt 重新读取屏幕 DPI。

## 更新检查

更新检查默认以无认证方式访问 GitHub Release。不要在源码中写入 GitHub PAT。只有在需要提高 GitHub API 请求额度时，才在本机设置环境变量：

```powershell
$env:LIFECALOR_GITHUB_TOKEN = "your-token"
```

程序会自动生成 `Bearer <token>` 请求头；该变量未设置时不影响软件本地功能。

## 工程结构

- `core/MainWindow.py`：应用入口、界面装配和跨模块信号协调。
- `core/DataManager.py`：Data、ProcessedData、ImagingData、ROI、显示转换和导出基础。
- `core/ImportManager.py`、`core/importing/`：统一导入请求、格式探测、导入器注册表和 HDF5 选择器。
- `core/DataProcessor.py`：EM-iSCAT、STFT/CWT、统计和通用处理算法。
- `core/LifetimeCalculator.py`：寿命拟合、热图、扩散和传热计算。
- `core/display/`、`core/ImageDisplayWindow.py`：显示源、异步帧渲染、播放策略、多画布和 ROI 交互。
- `core/calculator/`：多数据表达式、实时 Shape 验证、预览和 metadata 策略。
- `core/history/`、`core/dataio/`：历史 manifest、缓存管理和分块数组 I/O。
- `core/tasks/`：任务注册表、取消令牌、状态协调和任务面板。
- `core/processing/`：处理任务编排和 ProcessedData 结果路由。
- `core/memory/`：dtype 感知的内存估算和预算检查。
- `core/exporting/`：画布、图像和纯数据导出流程。
- `core/diagnostics/`：结构化错误、去重、日志和弹窗收束。
- `core/settings/`、`core/selection/`：参数读取、数据焦点和 ROI 选择策略。
- `core/performance/`、`benchmarks/`：性能记录与基准。
- `tests/`：数据模型、导入、缓存、显示、任务、错误和算法回归测试。

新增处理功能应遵循：参数收集 -> 后台任务 -> `ProcessedData` -> 结果路由 -> 绘图/画布/导出。新格式应实现独立 importer 并注册到 `ImporterRegistry`，避免继续扩张主窗口分支。

## 打包与仓库边界

现有 PyInstaller 配置位于 `LifeCalor.spec`、`core/LifeCalor.spec` 和 `core/MainWindow.spec`。实际发布前应确认使用哪一份配置作为唯一入口。

`build/`、`dist/`、`core/build/`、`core/dist/`、`__pycache__/`、日志、大型实验数据和临时图像均属于生成物或本地数据，不应作为核心源码维护或提交。
